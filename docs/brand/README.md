# AgePass brand

The AgePass mark is a shield with a check: "verified, and protected".

| File                                               | Use                                     |
| -------------------------------------------------- | --------------------------------------- |
| `agepass-icon-1024.png`, `agepass-icon-512.png`    | Avatar / submission icon (square, dark) |
| `agepass-icon.svg`                                 | Same, vector                            |
| `agepass-mark.svg`, `agepass-mark-1024.png`        | Shield only, transparent background     |
| `agepass-logo-dark.png`, `agepass-logo-dark.svg`   | Logo + wordmark on dark                 |
| `agepass-logo-light.png`, `agepass-logo-light.svg` | Logo + wordmark on light                |

Colours: accent `#34e0a1`, shield `#12204a`, background `#070e22`, text `#eef3ff` / `#0b1530`.
Wordmark: Inter ExtraBold. The PNGs are the exact renders; the lockup SVGs need Inter installed.
